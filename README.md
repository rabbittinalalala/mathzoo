# 🐾 動物數學樂園（MathZoo）

給中高年級小學生練習**加減乘除**的網頁小遊戲。純 HTML + CSS + JavaScript，不需要安裝任何套件，手機、平板、電腦的瀏覽器都能玩。

## 1. 功能一覽

- **隨機出題**：加、減、乘、除混合，每回合 15 題，減法不會出現負數，除法一定整除
- **四種難度**：簡單／中等／普通／困難
- **答題方式**：螢幕數字鍵盤（電腦也可以直接用鍵盤輸入，Enter 確認）
- **可重答 1 次**：第一次答錯可以再試一次，兩次都錯會顯示正確答案
- **不限時但計時**：回合結束顯示用時（切到別的分頁或鎖螢幕時會自動暫停計時）
- **回合結果**：答對題數、用時、獲得星星、錯題檢討
- **今日統計**：主選單顯示今天的遊戲次數與總遊玩時間
- **獎勵**：⭐ 星星、🐾 等級（蛋寶寶 → 獨角獸）、🏅 徽章（共 13 種）
- **3 位玩家**：各自暱稱、動物頭像，紀錄分開存
- **家長模式（PIN 保護）**：每日／每週統計、歷史紀錄、錯題檢討、每日時間上限、匯出／匯入備份
- **音效與動畫**：預設開啟，可在「設定」關閉

## 2. 快速開始（在自己的電腦試玩）

任選一種：

**方法 A：直接開檔案（最簡單）**
雙擊 `index.html`，用 Chrome 或 Edge 開啟即可。

**方法 B：VS Code Live Server（改程式時最方便）**
1. 安裝 [VS Code](https://code.visualstudio.com/)
2. 安裝外掛 **Live Server**
3. 在 `index.html` 上按右鍵 → **Open with Live Server**
4. 存檔後網頁會自動重新整理

**方法 C：Python 內建伺服器**
```bash
cd mathzoo
python -m http.server 8000
```
再用瀏覽器開 <http://localhost:8000>。同一個 Wi-Fi 下，手機也可以用 `http://電腦的區網IP:8000` 試玩。

> ⚠️ 紀錄是依「網址」分開存的。用「雙擊開檔案」、`localhost`、GitHub Pages 網址玩，三者的紀錄**互不相通**。正式給孩子玩，請固定用同一個網址。

## 3. 放到網路上：GitHub Pages 部署步驟

放上去之後，手機、平板直接開網址就能玩。

### 3-1 用網頁操作（不需要安裝 Git）

1. 登入 [github.com](https://github.com)（沒有帳號先註冊）
2. 右上角 **＋ → New repository**
   - Repository name：`mathzoo`（可自訂）
   - 選 **Public**（免費帳號的 GitHub Pages 需要公開儲存庫）
   - 按 **Create repository**
3. 在新儲存庫頁面點 **uploading an existing file**
4. 把 `mathzoo` 資料夾**裡面的東西**（`index.html`、`css`、`js`、`README.md`）全部拖進去
   - 重點：`index.html` 要在儲存庫的**最外層**，不要多包一層資料夾
5. 按 **Commit changes**
6. 上方 **Settings → Pages**
   - Source 選 **Deploy from a branch**
   - Branch 選 **main**，資料夾選 **/ (root)**，按 **Save**
7. 等 1～2 分鐘，頁面上方會出現網址：
   `https://你的帳號.github.io/mathzoo/`

### 3-2 用 Git 指令

```bash
cd mathzoo
git init
git add .
git commit -m "動物數學樂園第一版"
git branch -M main
git remote add origin https://github.com/你的帳號/mathzoo.git
git push -u origin main
```
之後同 3-1 的第 6、7 步開啟 Pages。

### 3-3 更新程式

修改後重新上傳（或 `git add . && git commit -m "更新" && git push`），等 1～2 分鐘生效。如果手機看起來還是舊版，把網頁**重新整理**或清除該網站的快取。

### 3-4 關於隱私

- 網址是公開的，知道網址的人都能開啟遊戲。
- 但**孩子的暱稱、成績都只存在各自裝置的瀏覽器裡**，不會上傳到 GitHub，所以不會外流。

## 5. 遊戲規則

### 難度

| 難度 | 加減法 | 乘除法 | 星星倍率 |
|---|---|---|---|
| 🌱 簡單 | 到 2 位數（和不超過 99） | 2～5 的乘法表 | ×1 |
| 🌼 中等 | 到 2 位數（和不超過 99） | 4～9 的乘法表 | ×1.25 |
| 🌿 普通 | 到 3 位數（和不超過 999） | 2～9 的乘法表（9×9） | ×1.5 |
| 🌳 困難 | 3 位數，**一定要進位／退位** | 2～9 的乘法表（9×9） | ×2 |

- 四種運算盡量平均出現（15 題大約每種 3～4 題），順序隨機，同一回合不會重複。
- 除法由「商 × 除數」反推，所以一定整除，除數最小是 2。
- **第二階段（家長模式可開啟）**：乘法與除法加入「2 位數 × 1 位數」，普通／困難難度各有一半機率出現，簡單、中等難度不受影響。

### ⭐ 星星

| 情況 | 星星 |
|---|---|
| 第一次就答對 | 3 顆 |
| 重答答對 | 1 顆 |
| 兩次都錯 | 0 顆（不扣分，會顯示正解） |

**回合總星星** ＝ 四捨五入（基本星星 × 難度倍率）＋ 加成

- 🏆 15 題全部第一次答對：額外 +10
- 🎯 正確率 80% 以上（第一次或重答答對都算）：額外 +5（與上面可以同時拿到）
- 加成不乘難度倍率。

例如：困難難度、15 題全部第一次答對 ＝ 45 × 2 ＋ 10 ＋ 5 ＝ **105 顆**。

### 🐾 等級

| 等級 | 名稱 | 累積星星 |
|---|---|---|
| 1 | 🥚 蛋寶寶 | 0 |
| 2 | 🐥 小雞 | 100 |
| 3 | 🐰 兔兔 | 250 |
| 4 | 🐱 小貓 | 500 |
| 5 | 🐶 小狗 | 800 |
| 6 | 🐻 小熊 | 1200 |
| 7 | 🦁 獅子 | 1800 |
| 8 | 🦄 獨角獸 | 2500 |

升級時會有慶祝動畫和音效。

### 🏅 徽章（13 種）

| 徽章 | 條件 |
|---|---|
| 🐣 初次登場 | 完成第一回合 |
| 💯 滿分達人 | 一回合 15 題全部第一次就答對 |
| 🔥 十連擊 | 連續 10 題都第一次就答對（同一回合內） |
| ➕ 加法王／➖ 減法王／✖️ 乘法王／➗ 除法王 | 該運算累積答對 100 題（各一枚） |
| 🛠️ 錯題終結者 | 重答答對累計 20 題 |
| 🦁 挑戰者 | 完成第一次困難回合 |
| ⚡ 打破紀錄 | 刷新自己「同難度」的最快用時（該回合正確率要 80% 以上，且之前已有同難度紀錄） |
| 📅 三日連玩／🗓️ 七日連玩 | 連續 3 天／7 天都有玩 |
| 🌟 週週有玩 | 同一週（週一到週日）玩滿 5 天 |

### 設計原則

- 只跟自己比，**沒有玩家排行榜**，避免孩子互相比較。
- 答錯不扣星星。

## 6. 家長模式

在「選玩家」畫面或主選單點 **👨‍👩‍👧 家長模式**。

- **第一次使用**會要求設定 4 位數 PIN；之後每次進入都要輸入。
- 連續輸入錯誤 5 次，會鎖定 30 秒。

### 📊 統計
今天／本週／累計（次數、時間、正確率、星星）、最近 7 天明細、近 4 週統計、各運算「第一次就答對」比率（可看出孩子哪種運算比較弱）。

### 📜 歷史
每一回合的紀錄，點開可看錯題與孩子的作答。

### 🔧 設定
- **每日時間上限**：不限制／15／30／45／60／90／120 分鐘（每位玩家各自計算）。達到上限後當天不能再開始新回合，進行中的回合可以玩完。預設不限制。
- **第二階段題目**：開關「2 位數 × 1 位數」（只影響普通、困難）。
- **玩家管理**：修改暱稱／頭像、刪除玩家、新增玩家（最多 3 位）。
- **備份**：匯出／匯入紀錄檔。
- **修改 PIN**、**清除全部資料**。

### 忘記 PIN 怎麼辦？
PIN 只存在這台裝置的瀏覽器裡。忘記時只能**清除這個網站的瀏覽器資料**（會一併清空所有玩家與紀錄），所以建議定期「匯出紀錄檔」備份。

> PIN 的目的是擋住小朋友，不是高強度的資安機制。

## 7. 資料存在哪裡？備份與換裝置

- 資料存在**瀏覽器的 localStorage**（key 名稱：`mathzoo.v1`），**每個裝置、每個瀏覽器各自一份**，手機、平板、電腦的紀錄不會互通。
- 以下情況紀錄會消失：清除瀏覽器資料、使用無痕／私密模式、換瀏覽器、換網址。

### 備份
家長模式 → 🔧 設定 → **⬇️ 匯出紀錄檔**，會下載 `mathzoo-backup-日期.json`。檔案包含玩家與所有回合紀錄（**不含 PIN 與音效等設定**）。

### 還原／搬到另一個裝置
家長模式 → 🔧 設定 → **⬆️ 匯入紀錄檔**，選擇：
- **合併**：保留這台裝置現有資料，只加入備份裡沒有的紀錄（重複匯入不會重複計算）
- **取代**：用備份檔完全取代這台裝置的玩家與紀錄

匯入後星星與等級會依紀錄重新計算。

## 8. 檔案結構

```
mathzoo/
├── index.html        頁面骨架（載入 CSS 與 JS）
├── README.md         本說明檔
├── css/
│   └── style.css     樣式與動畫（最上面 :root 可改主題色）
└── js/
    ├── util.js       共用設定（人數、題數、頭像）與小工具
    ├── questions.js  出題規則（難度、整除、進退位）
    ├── rewards.js    星星、等級、徽章規則
    ├── storage.js    資料儲存、統計、匯出／匯入、PIN
    ├── ui.js         音效、彩帶動畫、彈窗、提示訊息
    └── app.js        各畫面與遊戲流程
```

- 動物頭像直接用 emoji，音效用瀏覽器即時合成，所以**不需要圖片或音檔**，也不需要 `assets` 資料夾。
- JavaScript 沒有使用 `import`／模組，所以雙擊 `index.html` 就能執行。
- 載入順序有相依關係（`util → questions → rewards → storage → ui → app`），新增檔案時請維持這個順序。

## 9. 想修改？常見修改位置

| 想改什麼 | 檔案與位置 |
|---|---|
| 各難度的數字範圍、倍率、是否一定進退位（新增難度也在這裡，並加進 `LEVEL_ORDER`、`js/storage.js` 的 `VALID_LEVELS`、`css/style.css` 的 `.lv-xxx` 顏色） | `js/questions.js` 的 `LEVELS` |
| 乘除的「2 位數 × 1 位數」範圍 | `js/questions.js` 的 `twoDigitRange()`、`genMul()`、`genDiv()` |
| 星星數、加成、正確率門檻 | `js/rewards.js` 最上方的常數 |
| 等級名稱與門檻 | `js/rewards.js` 的 `LEVEL_TABLE` |
| 新增／修改徽章 | `js/rewards.js` 的 `BADGES`（`check` 函式回傳 `true` 就得到徽章） |
| 每回合題數、玩家人數上限、PIN 位數、頭像清單 | `js/util.js` 的 `MZ.CONFIG` |
| 顏色、字體大小 | `css/style.css`（最上方 `:root` 變數） |
| 音效音調 | `js/ui.js` 的 `SOUNDS` |
| 網頁標題 | `index.html` 的 `<title>` |

> 修改每回合題數時，徽章說明文字裡的「15 題」是寫死的字，需要一併修改。

## 10. 開發環境

| 項目 | 需求 |
|---|---|
| 執行 | 任何現代瀏覽器（Chrome、Edge、Safari、Firefox，手機版也可以）|
| 編輯 | 任何文字編輯器，建議 VS Code ＋ Live Server 外掛 |
| 部署 | GitHub 帳號（Git 可選）|
| 套件／建置 | **不需要**（沒有 npm、沒有打包工具）|

資料儲存使用 `localStorage`、PIN 雜湊使用 Web Crypto（需要 `https` 或 `localhost`，不支援時會自動改用簡易雜湊），GitHub Pages 預設是 `https`，兩者都可正常運作。

## 11. 常見問題

**Q：沒有聲音？**
檢查遊戲「設定」的音效是否開啟；iPhone 請確認側邊靜音開關沒有打開、媒體音量有開。手機瀏覽器要「點過畫面」才會發聲。

**Q：紀錄不見了？**
可能是用了無痕模式、清除了瀏覽器資料、或是用不同網址／瀏覽器開啟。請固定用同一個網址和瀏覽器，並定期匯出備份。

**Q：三個孩子年齡差 3 歲，難度怎麼辦？**
每位玩家會記住自己上次選的難度，下次進入選難度畫面時會標示「上次玩的」。

**Q：電腦上可以不用滑鼠嗎？**
可以。答題時直接按數字鍵輸入，`Backspace` 刪除，`Enter` 確認；答錯兩次後按 `Enter` 進下一題。

**Q：想讓孩子少玩一點？**
家長模式 → 設定 → 每日時間上限。

**Q：「總時數」是怎麼算的？**
是每個回合「實際作答時間」的總和（切走分頁或鎖螢幕的時間不計），不是開著網頁的時間。
